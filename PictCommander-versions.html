// About

PictCommander is a file manager and viewer built around photographs, with a photo editor inside. Browse a shoot six different ways, compare frames and keep the best, rename a hundred files at once, crop and straighten, blur a stranger's face, take a wire out of the sky — all in one window, without a separate program for every job.

Built-in AI. The LaMa neural network removes people, wires and clutter from a photo, fills in empty corners after rotation and takes glare off glasses — right on your computer, offline, with no subscription. Your originals stay untouched until you decide otherwise.

Two languages: English and Russian

The interface and the illustrated user manual come in English and Russian. The program starts in English; to switch, open Tools → Settings (Ctrl+,) → General → Interface language and restart.

The video tutorial is in Russian, and there is no English one yet. Everything it shows happens on screen, though, and with the interface in English you can follow along without understanding a word of the narration.

What it does not do

It is not Photoshop: there are no image layers or masks, and serious retouching belongs in a professional editor. RAW and PSD files are read but never overwritten — your edits are saved as a JPEG or PNG copy. The neural network rebuilds sky, grass, foliage and walls convincingly, but it will invent faces and lettering of its own. The map and Street View need an internet connection; nothing else does.

Windows Defender and antivirus software

The program is not yet registered with Microsoft, so Windows Defender may report PictCommander.exe as malware (for example Trojan:Win32/Wacatac.B!ml) or remove it while unzipping. This is a false positive, common for programs written in Python. PictCommander installs no services, does not add itself to startup and sends no data anywhere.

If it happens, restore the file from Windows Security → Protection history and add the program's folder to the exclusions. If a blue "Windows protected your PC" window appears, click "More info" → "Run anyway". Antivirus.txt inside the archive has the details. A review request to Microsoft is on its way.

Getting started

Unzip the archive somewhere inside your user profile — for example %LOCALAPPDATA%\Programs\PictCommander — and run PictCommander.exe. No installation and no administrator rights are needed. Avoid the root of drive C: and Program Files: the program may lack the rights to read from there and hang with an empty drive list.
