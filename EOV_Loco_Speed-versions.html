A new speed for a Maya walk or run cycle: longer or quicker steps, no foot sliding

// About

EOV Loco Speed changes the speed of a walk, run or strafe cycle in Maya without the feet sliding on the floor. The stride gets longer or quicker, the pelvis drops as much as it has to, planted feet stay put and the cycle stays seamless. It does not replace your hand work - it gives you a clean base for it, in two clicks.

Three clicks

Select any control or joint of the character and press Detect from selection: the tool finds the pelvis, feet and arm controls and reads the cycle from the playback range. Type a new speed and press Apply as a copy. That is it.

The target, your way

Set the speed in km/h, in metres per cycle or in percent of the source. The Longer steps ↔ Faster steps slider decides how to get there: wider steps at the same tempo, the same step more often, or half and half, the way a real person speeds up. Need a cycle of exactly 30 frames for the engine? Cycle frames sets the length by hand, Whole frames rounds it to whole frames.

See it before Apply

While you drag the slider, three lines lie on the floor: where the cycle starts, where it ends now and where it will end with the new target. The summary shows speed, stride, frames and how far the pelvis drops - before and after. The scene itself does not change until you press Apply.

Honest limits

The tool knows what this character can do without changing the gait: how far the legs reach and which tempo still reads as the same walk. Near the limit the line turns yellow, past it red, and the reason is spelled out. An exaggerated stride can still be applied - sometimes that is exactly the point.

Rigs and mocap

It works on a rig (IK leg controls) and on a bare keyed skeleton - mocap or a Mixamo FBX. On a skeleton the tool solves the legs itself and leaves no IK handles or helper nodes behind. World-space arm controls - IK, poles, props - ride with the body; the Carried list can be edited by hand.

Any direction

Forward, back, strafe, diagonal: the stride changes along the character's real path. The tool names the direction from where the head looks; if it guesses wrong, pick the right one in the Moves list.

In place and root motion

Both work. For an in-place clip there is Travel: it carries the character along the floor so the feet stop sliding back while you watch. It does not touch the keys, and Keep result turns it off before export.

The result is a copy

Apply writes the result next to the original: Original and Result switch between them in the viewport, and both are saved with the scene. The whole Apply is one undo step. Happy with it? Keep result keeps the result, removes the copy of the original and the tool's nodes - the scene is ready for export.

Rig presets

Setup fixes and the rig's working speeds - walk, run, crouch - are kept in a preset. In the next scene with the same rig the preset switches on by itself after Detect, and you can hand it to a colleague as a file.

What it does not do

  • it does not change the style of the walk or add physics: it stretches and speeds up your cycle, the polish is yours;
  • it does not read animation layers or character sets - plain keys only; merge or bake the layers first;
  • it does not work on one character inside a shared scene: a new cycle length retimes every curve in the scene except cameras', so move other characters to a scene of their own;
  • it does not touch the original until you press Keep result;
  • it does not go online.

Manual

An illustrated manual in English and Russian opens from "?" → User Manual. The pictures carry numbered callouts: hover a line and the spot lights up. Search covers every section.
