EOV FileOrganizer v1.0.0

a catalog of your disks and DVDs: find any file, even inside archives, offline

// About

EOV FileOrganizer keeps a catalog of your disks, flash drives and CDs/DVDs. It reads a disk once, remembers every folder and file on it, and from then on you search that list, even while the disk sits in a drawer. Archives are searched inside, too, and several catalogs can be searched at once.

Every disk is a branch

An external HDD, a flash drive, a DVD from the box, a network share or just a folder of projects all go into one catalog, each as its own branch of the tree. Next to every disk you see whether it is connected right now, and a bar shows which folders take up the most space.

The tree can be classic, with +/− and dotted lines just like Advanced File Organizer, or modern, with thin guides.

Inside archives as well

ZIP, 7z, TAR and RAR are read during the scan. Only the archive's table of contents is read and nothing is unpacked, so even a big archive adds a fraction of a second. In the tree an archive opens like an ordinary folder. RAR needs WinRAR installed; the program finds it by itself.

Fast search

Wildcards (an asterisk and a question mark) and several masks separated by semicolons - say, every Photoshop and Blender file in one query. Search can be case sensitive, exact, files only or folders only, with or without archives, in descriptions, by date and by size, and within the previous results. Search the whole catalog, one disk or one folder.

On a working disk with 1.2 million files the first scan took under six minutes; a search over the finished catalog takes a tenth of a second.

Search several catalogs at once

Home archive in one .efo, work in another, old DVDs in a third? No need to open them one by one. Select several .efo files in the Open dialog and they open together, each as its own branch of the tree, and a search runs through all of them. The results show which catalog every file comes from, and Go to in Catalog takes you straight into the right branch.

The set can be saved as a collection, an .efoc file, and opened next time with a double click. A collection is for browsing and searching; to change a catalog, open it on its own with one command from the menu.

Found it, now use it

Open the file (a file from an archive is extracted to a temporary folder), show it in Explorer, go to it in the catalog tree, or copy its path. When the disk is not connected, the program tells you so, and which disk to fetch.

Disks are recognised by themselves

The program remembers the volume serial number, not the drive letter. A flash drive scanned as E: and plugged in today as F: is still recognised, and Open goes to the right place. A rescan updates the disk in the catalog and keeps your descriptions.

Descriptions

Any disk, file or folder can carry a description: "the blue drive in the desk drawer", "final version, sent to the client". Descriptions of files and folders are searchable; a disk's description shows in its properties.

If you still have Advanced File Organizer catalogs

Advanced File Organizer was a popular disk cataloger built for the same job: people scanned hard drives, flash drives and stacks of CDs with it and kept the catalogs in .afo files. It has not been updated for many years, but plenty of those catalogs are still around, holding years of history of your disks.

If you have such files, there is nothing to rescan. File > Import Advanced File Organizer Catalog opens an .afo and turns it into an ordinary catalog: disks, folders, files, archive contents and descriptions come across as they are. Convert .afo Catalogs to .efo handles a whole batch: an .efo with the same name appears next to each .afo, and the originals are left alone. A catalog of 17 disks and 7 million files moves over in under a minute.

What it does not do

It does not watch your disks: when a disk changes, rescan it. It does not read what is inside files, shows no previews and never touches the files on your disks - it only keeps their list. It never goes online and runs on Windows only.
