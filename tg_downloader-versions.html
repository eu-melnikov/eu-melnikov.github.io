// About

Free and open source under the MIT licence: the source code ships in the same archive as the program.

Telegram Media Downloader screens the Telegram chats, groups and channels you choose — by itself, on a timer. It collects files and conversations, sorts them by day and sender, and remembers edits and deletions. What builds up on your disk is a dataset you can use however you like, from searching every chat at once to statistics and AI summaries.

The idea

"But Telegram can save chats too," you might say. It can — by hand, one export at a time. Telegram Media Downloader does it automatically and continuously, and that is the whole difference.

You decide what to collect: which chats, which file types, whether to keep the text, from which date. The result is a dataset that supports statistics Telegram's own tools could never offer. And in the age of AI such data is quick to work with: classify it, look for patterns, build summaries. It is a straightforward way to build a dataset of your own.

New in 2.30.0

  • Groups and supergroups. Group chats are monitored just like people, including groups without a @username, which used to come back as "Not found". Every file from a group is named after the member who sent it (John Smith__photo.jpg), and the journal and reports show the sender above each message.
  • Quick checks. A regular check looks only at what arrived since the previous one, plus the last 24 hours to catch fresh edits and deletions. The point a check has reached moves on only once everything it found is downloaded, so nothing slips through.
  • Full check. Right-click a contact and the program walks everything from the start date again: fetches anything missed, re-downloads replaced files, marks deleted messages. It also runs by itself on the first check and after the start date, folder or file types change.
  • A diagnostic log with no private data. No message text, names, usernames, phone numbers or file names; chats appear as short codes. Safe to attach to a bug report.

Open source

A program that logs in to your Telegram account should not be a black box. The source code comes in the same archive as the program, with a one-click build script (build.bat). Anyone can check what it does with the account and build the exe themselves. No telemetry: it talks only to Telegram's servers, using your own API keys.

Monitoring: the data collects itself

A list of people, groups and channels the program watches on its own. Every few minutes (1 to 60, five by default) it checks them and fetches new files of the ticked types — video, photos, documents, archives, audio — into a separate folder per contact, by day, and records the text of the conversation along the way. It can start with Windows and run from the tray, so by the time you reach the desktop the fresh material is already in.

One report, search across every chat

The "History Machine" button turns the conversations with your monitored contacts over a chosen period into a single HTML page. It opens in a browser and needs no internet. Inside: the conversations by contact, a feed of all days at once, and search across every chat together. Telegram itself only searches within one chat. Older history, from before the program was installed, can be loaded into the journal with a right-click on the contact.

One-off download of any chat

The other tab is a plain downloader: pick a chat, channel or group, set the dates and file types, press Scan to see how much is there and how much is new, then Download fetches it in several threads. What is already on disk is not fetched twice.

Replaced, edited, deleted — nothing is lost

The program never wipes what it has saved. If someone swaps a file, the new one is downloaded and the old one stays beside it marked _old. An edited message is marked "edited", a deleted one "deleted", and it stays in the archive. You keep an honest history of the conversation, not whatever is left in the chat after other people's changes.

The session is stored safely

The Telegram login is kept not next to the program but in your Windows profile, and the authorization key is encrypted by Windows (DPAPI) for your account. You can hand the program folder to someone else — access to your account does not travel with it.

What it does not do

  • It never sends or writes anything in Telegram on your behalf — it only reads your account and saves data to disk.
  • It does not run any AI on the data or send it anywhere: it builds the dataset, and you decide what to process it with.
  • It does not delete files or messages: deletions are only marked, replacements are kept beside the new file.
  • It does not monitor while closed: checks run while the program is open or in the tray.
  • It does not move the session to another computer: after reinstalling Windows you log in again. That is deliberate.
  • Windows only, and only your own account (free API keys and a one-time phone login are needed).
