EOV NetPulse v1.0.0

An internet monitor in the tray: outage alerts, actions on loss and restore, a log

// About

EOV NetPulse watches your internet connection from the tray and tells you the moment it drops — even when Windows is in Do Not Disturb. When the connection goes and when it comes back, it can close, start or restart the programs you choose, and it logs every outage: when it happened, how long it lasted and what exactly failed.

A popup that Do Not Disturb cannot hide

When the internet drops, NetPulse shows its own window above the clock: on top of everything, without stealing focus, with the reason and the time. It is not a Windows notification, so Do Not Disturb does not hide it. You choose where it appears (above the clock, top right or screen center), the sound (short or alert), and whether the outage popup stays until you close it. When the internet is back, NetPulse tells you that too, with the time and the length of the outage.

If you want a regular Windows notification as well, it is there. NetPulse puts its own shortcut in the Start menu so that you can add it to the priority list in Windows settings.

You see what actually failed

Every few seconds NetPulse checks the connection several ways at once: the network link and the router, ping to public addresses, DNS bypassing the Windows cache, and a test page — the same one Windows itself uses. From the answers it tells you which case it is: No network (cable, Wi-Fi or router), No internet (the network is fine, nothing gets out), DNS is down or Unstable. A hotel or airport Wi-Fi login page is recognised and not mistaken for the internet.

An outage counts only after several failed checks in a row (three by default), so a single lost check does not raise the alarm. The check interval, the threshold and the addresses are all in the settings.

Actions on loss and on restore

The Actions tab has two lists: On loss and On restore. Each can hold:

  • a popup window;
  • a Windows notification;
  • close programs;
  • start programs (with arguments);
  • restart programs.

Pick programs from the running ones or with Browse. Drag to change the order.

Delays, so a blip breaks nothing

Every action has its own delay. On loss it is "if the internet has been down for" — say, a message at once and closing a program after two minutes. If the internet comes back earlier, the pending action is cancelled by itself. On restore it is "only if the outage lasted at least" — so a short blip does not restart anything.

While an action is waiting you see how long is left, and you can cancel it. All actions with programs can be paused from the tray: for an hour, until NetPulse restarts, or until you turn them back on.

It closes programs with care

Closing and restarting have two modes. Politely first is like clicking the X: the program gets to save its work, and if it is still open after the wait, it is closed by force. Force at once closes it straight away, and unsaved work is lost. System processes are not listed and are never closed, whatever the settings.

The journal and the internet pulse

Every outage goes into the journal: the start, the duration, the kind (no network, no internet, DNS) and what NetPulse did about it. Above the list runs a pulse line, like the graphs in Task Manager: flat while the internet was there, a spike where it was gone — the longer the outage, the taller the spike. Pick today, 7 days, 30 days or all time, and see the number of outages, the time offline and the percentage online. The window header shows a strip for the last 24 hours.

Export the journal as a report for reading (HTML) — one file with the chart and the table that opens without internet and can be sent to your provider — or as a table for Excel (CSV).

Quiet in the tray

NetPulse starts with Windows, minimized to the tray, and stays out of the way. The color of the line on its icon shows the state: all good, unstable, no connection, or actions paused. The tray menu lets you check now, open the journal, pause actions and cancel pending ones. Only one copy ever runs, so an accidental second start does not double the popups, the actions or the journal entries.

English and Russian interface, dark and light theme (or as in Windows), three icon styles to choose from.

What it does not do

It does not fix the internet: no reconnecting Wi-Fi, no rebooting the router, no changes to network settings — it warns you and runs the actions you set up, nothing else. It does not measure speed. It does not send messages to your phone or e-mail. It runs without admin rights, so it cannot close a program started as administrator — and it says so in the popup and the journal. There is one set of settings per user, no profiles like "home" and "office". Windows only.
