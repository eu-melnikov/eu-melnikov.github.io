// Update news

2026-10-26 🕒 High Level Tracker 2v2.0.2 2.0.2 is a small update to the Work screen: a busy day no longer stretches the page, clips carry no long names at their side, and the pop-up tooltips are gone. Changed The theses of the day scroll. On a day with many tasks done, the list on the right no longer grows into a long sheet that pushes the week down: the card stays short and the rest scrolls inside it. No names beside the clips on the day track. A task's name is written only inside its clip and cut with "…" when it does not fit. The full name is on the right panel when the clip is picked. No pop-up tooltips. The long tooltips over clips, buttons and fields are gone: everything they said is in the manual (F1). The only one left shows where a record lands while you drag it. Installing and updating Quit the program, delete everything in the HLT2 folder except settings.json and secrets, and unzip the new archive into the same place. Journals, settings and the Telegram sign-in stay. 2026-10-24 📷 PictCommanderv1.02 1.02 is a small update: PictCommander can be made the default photo viewer on current Windows 11 again, opens photos from Explorer and builds thumbnails faster, and the Help menu now has an update check. Fixed Default program on current Windows 11. Recent Windows 11 no longer lets a program make itself the default, so the ticks under File associations could quietly do nothing. PictCommander now lists itself in Windows Settings (Default apps → PictCommander), checks what a double-click will really open, and when Windows holds on to another program it offers an "Open Windows Settings" button that goes straight to the right page. Faster Photos from Explorer. Opening a JPEG no longer loads the PSD library along with it - the photo is up about a second and a half sooner. Thumbnails of camera photos are built about two and a half times faster, with no visible difference in quality. Nearest first. Open a photo from the middle of a big folder and the thumbnails around it appear first, not after every one before it. New Help → Check for updates opens the PictCommander versions page in your browser. The manual has a section on updating and a tip to keep the program on an SSD. Installing and updating The folder in the archive is now just PictCommander, with no version number. To update, close the program, delete what is in its folder (_internal included) and unzip the new archive in the same place. Settings, favourites and the thumbnail cache are kept elsewhere and are not touched. After updating, open Tools → Settings → File associations once and press Apply - the program will list itself in Windows Settings. 2026-10-24 🕒 High Level Tracker 2v2.0.1 2.0.1 is a small bug-fix update: files under a newly added review mask are now found in older messages too, a long name on the day track is no longer written twice, and the Help menu can check for updates. Fixed Files from chats under a new mask. A review mask added later (.zip, say) used to catch only files sent after it: whatever came before had already been read past. Now a new mask makes the chats be read again over the last 30 days. From what was read before, only files under the new mask are taken, so reviews you deleted do not come back. A long name on the day track. When a name did not fit its clip, it was written a second time to the right of it - and showed up twice. Now only really narrow clips are labelled at the side; everywhere else the name is cut with "…", and the full one is in the tooltip. New Help → Check for updates opens the page with the versions of HLT 2 in the browser. Installing and updating The program folder is now one for every version - HLT2, with no number; the number is only in the name of the archive. To update, quit the program, delete everything in the folder except settings.json and secrets, and unzip the new archive into the same place. Coming from 2.0.0 (folder HLT2-2.0.0): move settings.json and secrets into the new HLT2 folder once. If starting with Windows was on, the new HLT2.exe points Windows at itself. The manual and the README cover this in their section on updating. 2026-10-23 🎬 Frames Commanderv1.22.5 1.22.5 is a small update: it adds hotkey support to Recent Personal, the personal-folders mode that came in 1.22. Each name can now have a key of its own, so a person's newest video opens with a single keystroke, no menu needed. Recent Personal Settings → Recent Personal has a new Hotkey column. Click Set…, then press a key or a combination such as Ctrl+1. Esc cancels, the ✕ button removes the key. The key does what clicking the name does: in normal mode it opens the newest video, in Split the previous take goes left and the new one right. The same works in Maya Mode and Overlay Pro with Side-by-Side on. The menu shows the key next to the name, and it works with any keyboard layout. A key that already runs a regular action can't be taken — you get a warning. A key used by another name can be moved over, and the Hotkeys tab asks before taking a key away from a name. The manual The Recent Personal section explains the new keys, and Troubleshooting covers a name key that stopped working.
