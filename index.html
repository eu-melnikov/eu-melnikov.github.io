2026-08-18 🔧 FuryNotesv1.2.0 Icons for notes. A note can be given a picture, and it stands in front of its name in the tree. Fifty-odd to choose from: an aeroplane, books, a guitar, a lightbulb, a rocket, a heart, smileys, music notes, a calculator and so on. The point is simple — in a column of similar names the eye finds a shape faster than it reads words. Right-click a note → "Icon", then the grid; one click and it is there. "No icon" in the same menu takes it off. The icon belongs to the note: rename it or move it to another folder and the icon goes along, the way a colour and a pin already do. It also travels to another computer — only the icon's name is kept beside the note, and the picture itself is inside the program at both ends. A colour of its own for each icon. Under the grid are ten neon colours. The one you pick paints that icon, not all of them, so you can tell things apart: work in blue, home in green, urgent in red. "Default colour" puts it back. The colour knows about the theme. What is stored is really the hue, and how light to draw it is worked out again for the background in use. That is why the same note looks right on the dark theme and on the light one — a vivid yellow-green that glows on black would otherwise simply vanish on white. Neon and a glow, if you want them. Two tick-boxes in the settings. "Neon note icons" paints every icon that has no colour of its own in your accent colour. "with a glow" lights a halo around them — the neon outline itself. Both are off as the program ships: this is a taste, not the way the program has to look. The glow is drawn into the empty margins around the icon, so not one name in the tree moves by a single pixel. Back and forward, like a browser. Two arrows on the toolbar, and Alt+← / Alt+→, walk the notes you have already opened. The side buttons on your mouse do the same. The trail follows the notes rather than the files: a note that has since been deleted is not a dead end — that step is skipped and the next one taken — and a renamed note keeps its place in the chain. An arrow with nowhere to go is drawn faded, so you can see at a glance whether there is anything behind you. You can see which note is open. A caret now stands in front of its row and its name is a shade brighter than the rest. Before this, coming back to the program meant working out where you had left off. A pinned note keeps its bookmark at the same time — the marks no longer push each other out. Two gestures on a folder instead of one. The folder's icon opens and closes it, the name only selects it, and a double click on the name opens it. Before, a click anywhere on the row toggled the folder, so it could not be chosen as the place for a new note without flapping open on the way. Two vertical stripes down a selected row went at the same time: one was ours, the other was Windows painting its own accent colour, which answered to nothing in the theme. A new manual, one for everything. Instead of a stack of per-version documents there is now a single page: docs/manual. English and Russian switch with a button, and it has contents down the side and a search across the text. A "What's new" section carries a card per version, so a minute is enough to see what has appeared since you last updated. And the formatting section opens with a cheat sheet: one picture showing every kind of formatting at once, where each line names the keys that made it. Smaller fixes. Toolbar buttons that cannot be used now look switched off — before this, a "Back" with nowhere to go was as bright as a working one. 2026-08-10 ⚙️ BackDropv1.1 A FLOATING TOOLBAR, TWELVE PLACES TO PARK IT, BUTTONS ON THE PANEL ITSELF, Fixes 2026-07-30 🔧 FuryNotesv1.1.7 Row colours in the note tree. Hi, I'm Eugene Melnikov

Character animator since 2006. I lead an animation outsource division, mentoring animators and shaping the creative process from brief to final shot.

Alongside animation, I write Python scripts to improve pipeline workflows and smooth out collaboration between animation teams. My tools are born out of real production pain — if something is repetitive and boring, I automate it.

Building Windows utilities is part hobby, part pragmatism — 50/50. I enjoy thinking up features, optimising processes, and occasionally shipping something useful to the world for free.
