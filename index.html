2026-09-27 🔧 FuryNotesv1.4.2 Everything since 1.3.0, the last version on this page: 1.3.1, 1.3.2, 1.4.0, 1.4.1 and 1.4.2 were built one after another and arrive here together. A numbered list keeps its own count. You have a list of five and want one more after the second. Enter used to give you a second "3.", and every number below it had to be fixed by hand. Now the new item is 3, and the old 3, 4 and 5 become 4, 5 and 6 by themselves. Taking an item out works the same way. Delete it, backspace it away, cut it with Ctrl+X or clear several lines at once, and the numbers below close up. A list that starts at 5 still starts at 5. A nested list keeps its own count, and a blank line or plain text ends the list. One Ctrl+Z takes back the new line and the renumbering together. Only the digits change, so the cursor stays where it was. For now this happens from the keyboard. Pasting or cutting through the right-click menu and dragging text with the mouse leave the numbers alone. The manual opens from the program: F1. F1, or the book button on the toolbar between Settings and About, opens the user manual in your browser, in the language of the interface. It is now two pages, English and Russian, built from pictures of the program itself. The numbers on each picture point at the parts, and the list under it says what they do. There is a search box too. The manual sits in the "manual" folder next to FuryNotes.exe, so you can open it or send it on without the program. A note opens where you left it. Leave a note half-read, look at another one, come back, and you are on the same line instead of at the end. Anything you had selected is still selected. FuryNotes remembers the place for every note you open while it is running. Folders from elsewhere, right in the tree. Documents that live in someone else's folder, such as a project's papers or a shared drive, can now go on the tree without being copied in. Right-click the tree, choose "Connect an external folder…", give it a name, and its .md and .txt files appear as one list you can read and edit in place. FuryNotes writes nothing into that folder. "What to show from this folder…" lists everything in it with a tick box, so you can clear them all and tick the few you need. A single unwanted file is quicker to drop from the tree with "Hide from this folder". Anything that lands in the folder later shows up by itself. Ctrl+F finds these documents too, and earlier copies of their text are kept in your own notes folder. Read the folder again: F5. Drop a .md or .txt file into the notes folder from Explorer, from a download or from another program, and the ring button at the end of the top row (or F5) brings it into the tree. It also re-reads the open note if its text was changed from outside. Whenever you switch back to FuryNotes from another program, the tree is re-read by itself. The date comes with the time, and with a button. Ctrl+Shift+D now writes the date and the time, to the second: 2026-09-27 14:05:31. Two entries made on the same day no longer look like one. The calendar button at the end of the second toolbar row does the same thing with the mouse. 2026-09-25 ⚙️ BackDropv1.7 A release about the small things that eat time every day, and a new user manual. A waveform runs over the picture, an external track can be attached to a silent playblast, and captions on the frame live as objects you can edit at any time. Waveform over the frame A strip with the sound at the edge of the picture: the playhead runs along it, and hits and syllables are visible at a glance. The Zoom sets In/Out box ties the zoom to the segment when you want it. A key on the playhead line can now be selected, moved and deleted. Playlist order Reorder files by dragging and sort them by name — the review queue and the sequence come together in seconds. Also in this release Proper arrows on drop-downs and number fields, readable tooltips, buttons that keep their shape, Maya tools verified in every Maya 2019–2026, and an updated interactive manual in English and Russian. The update is recommended for all users of version 1.19. 2026-09-14 🎬 Frames Commanderv1.19 Version 1.19 grew out of feedback from 1.18 users. The headline feature is viewing several clips as one: select shots in the playlist and review the edit and the cuts between them, just like in RV — all the way to exporting the sequence as a single file. Alongside it come scrub audio for lip-sync, hotkeys for every drawing tool, settings that no longer reset, and a new visual HTML user manual. Clips as one sequence — like in RV Check the edit without assembling it in a video editor. Select clips in the playlist with Ctrl or Shift and press the As one sequence button at the bottom of the playlist. With fewer than two selected, the whole playlist goes in, in playlist order. One timeline for the whole sequence: cuts show as yellow ticks, frame numbers run straight through, and the current clip's name appears right on the frame (the N button). Shift+→ and Shift+← jump to the next and previous cut. Playback, Loop, In/Out points, scrubbing and scrub audio all work across cuts. Clips can differ: another resolution is letterboxed, a clip without sound plays silence, and variable-frame-rate screencasts stay in sync. A clip with a different fps is conformed to the sequence — the program warns you. Drawings and bookmarks are remembered per clip and its own frame: reorder the clips or open a clip on its own — the annotations stay in place. The sequence is saved into the .fcmd project with the position and segment. If a clip has gone missing from disk, the sequence is rebuilt from the rest. The sequence runs in the Normal mode; Split, 2x2 and other modes close it. Turn the button off and the clip under the playhead stays in the player, on the same frame. Exporting a sequence as one file Send the edit for review as a single video, not a pile of files. The regular Export (Ctrl+E) in sequence mode renders the In/Out segment across every cut into one MP4 with the sequence audio. The frames are exactly what the player shows, at the first clip's resolution. A JPEG sequence is numbered by sequence frames. Cancel stops the export and deletes the unfinished file. Scrub audio for lip-sync Hear a frame's sound when you move through the video by hand. The sound-wave button next to the volume, or Shift+S: every frame step plays a short slice of that frame's audio. It sounds when stepping with the arrows and dragging on the timeline or right on the frame; normal playback, jumps and bookmark navigation stay as before. Right-click the button to choose the slice length: 1, 2 or 3 frames. Works in Normal, Split and 2x2 modes (the active panel is voiced); the switch is shared and remembered. Off by default. Hotkeys for drawing Annotate without trips to the toolbar. 1–8 — pencil, vanishing ink, line, arrow, rectangle, circle, triangle, text. A digit turns drawing on by itself. "-" and "=" — line width or font size. Delete clears the frame's annotation immediately, without a prompt; Shift+Delete clears all frames, with confirmation. Both can be undone with Ctrl+Z. Button tooltips show the current keys; every key can be reassigned on the Hotkeys tab. Stability and convenience Settings no longer reset. The settings file moved to the user profile folder (%APPDATA%\FramesCommander): it is always writable, even when the program sits in Program Files, and a new version unpacked in place of the old one picks up your hotkeys. Old settings migrate automatically on first launch. A failed read no longer wipes the settings. Per-file bookmarks, just like drawings. Come back to a file in the playlist — its bookmarks are where you left them. Undoing Clear All works again: annotation cleared from every frame comes back with Ctrl+Z. Undo doesn't mix files up: after switching files, the previous file's undo steps are no longer applied to the new one. A new manual. An interactive HTML guide with annotated screenshots, step-by-step instructions, text search and sections for every mode. The Russian edition is ready; the English one is in progress. The update is recommended for all users of version 1.18.

Character animator since 2006. I lead an animation outsource division, mentoring animators and shaping the creative process from brief to final shot.

Building Windows utilities is part hobby, part pragmatism — 50/50. I enjoy thinking up features, optimising processes, and occasionally shipping something useful to the world for free.
